## Tarea

Implement the three input modules of the report generator: the TOML run
file, the JSON questions file and the Markdown corpus. The design is
`.claude/architect/designs/report-generator/design.md`, §3 (inputs) and §5.1
(corpus). Read it first: the TOML and JSON examples there are normative.

1. **`src/hermes_report/config.py`**, `__all__` = the names below.
   - `ConfigError(Exception)`: `__init__(self, path: Path, message: str, key:
     str | None = None)`. It keeps `path`, `key` and `message` as attributes.
     `str()` is `f"{path}: {key}: {message}"`, or `f"{path}: {message}"`
     when `key` is `None`. `key` is dotted (`"retrieval.top_k"`).
     Messages are in Spanish.
   - Frozen dataclasses, one per section, with the defaults of design §3.1:
     - `CorpusConfig(dir: Path, glob: str = "**/*.md")`;
     - `QuestionsConfig(file: Path)`;
     - `IngestConfig(max_chunk_size: int = 1500, hard_boundary_levels:
       tuple[int, ...] = (1, 2), strip_frontmatter: bool = True)`;
     - `EmbeddingConfig(provider: str = "ollama", model: str =
       "nomic-embed-text")`;
     - `QdrantConfig(url: str, collection: str = "")`;
     - `RetrievalConfig(top_k: int = 10, candidate_factor: int = 1,
       score_threshold: float | None = None)`;
     - `EnrichConfig(chain: tuple[str, ...] = ("neighbors", "merge",
       "doc_order"), max_context_tokens: int = 3000, max_chunks: int | None
       = None)`;
     - `GenerationConfig(provider: str, model: str, temperature: float =
       0.0, seed: int | None = 42, response_format: str = "plain",
       insufficient_message: str | None = None)`;
     - `JudgeConfig(enabled: bool, provider: str, model: str)`;
     - `OutputConfig(dir: Path, cache_dir: Path)`.
   - `Overrides` (frozen): `model: str | None = None`, `judge_model: str |
     None = None`, `no_judge: bool = False`, `top_k: int | None = None`,
     `budget: int | None = None`, `out: Path | None = None`, `only:
     tuple[str, ...] = ()`, `reingest: bool = False`.
   - `RunConfig` (frozen): `path: Path` (the run file, absolute), `title:
     str`, `description: str` (default `""`), the ten sections as fields
     named `corpus`, `questions`, `ingest`, `embedding`, `qdrant`,
     `retrieval`, `enrich`, `generation`, `judge` and `output`, plus `only:
     tuple[str, ...] = ()` and `reingest: bool = False`. Methods:
     - `to_dict(self) -> dict[str, Any]`: the resolved run file as plain
       data, in the TOML layout (top-level `title` and `description`, then
       one table per section). Paths are written as absolute strings,
       tuples as lists, and `None` values are left out. `only` and
       `reingest` are not included.
     - `to_toml(self) -> str`: `to_dict()` as TOML text, so that
       `load_config` of that text, saved in the same folder, gives an equal
       `RunConfig`. Write a small serializer: `tomllib` only reads. It only
       needs strings (escaped as TOML basic strings), ints, floats, bools
       and lists of those.
   - `load_config(path: Path, overrides: Overrides | None = None) ->
     RunConfig`, raising `ConfigError`:
     - The file must exist and be valid TOML (`tomllib`). The `tomllib`
       message goes into the error.
     - Relative paths are resolved against `path.parent`. This applies to
       `corpus.dir`, `questions.file`, `output.dir` and `output.cache_dir`.
       `corpus.dir` must be an existing folder and `questions.file` an
       existing file.
     - Required keys: `title` (non-empty), `corpus.dir` and
       `questions.file`.
     - Unknown top-level keys, unknown sections and unknown keys inside a
       section are errors that name the key.
     - Types are strict. A `bool` is never accepted as an int. An int is
       accepted where a float is expected.
     - Values:
       - `max_chunk_size >= 1`;
       - `hard_boundary_levels` is a non-empty list of ints in 1..6;
       - `embedding.provider` is `ollama` or `hash`;
       - `generation.provider` and `judge.provider` are `ollama` or `echo`;
       - `qdrant.url` is non-empty;
       - `qdrant.collection` is `""` or starts with `hermes_report_`;
       - `top_k >= 1` and `candidate_factor >= 1`;
       - `chain` is a list of names among `neighbors`, `merge` and
         `doc_order` (the built-ins);
       - `max_context_tokens >= 0`, where `0` means no limit;
       - `max_chunks >= 1` when given;
       - `temperature >= 0`;
       - `response_format` is `plain`, `markdown` or `bullets`;
       - `insufficient_message` is non-empty when given.
     - Environment defaults: `qdrant.url` defaults to `$QDRANT_URL`, else
       `http://localhost:6333`. `generation.model` defaults to
       `$OLLAMA_MODEL`, else `qwen3:4b`.
     - Judge defaults: `judge.provider` defaults to `generation.provider`
       and `judge.model` to `generation.model` (an empty string also means
       the default). `judge.enabled` defaults to `true`.
     - `output.dir` defaults to `out` and `output.cache_dir` to
       `.hermes-report-cache`, both relative to the run file.
     - Overrides apply after validation and are validated the same way:
       - `model` sets `generation.model`, and also `judge.model` when the
         run file left the judge model to its default;
       - `judge_model` sets `judge.model`;
       - `no_judge` sets `judge.enabled = False`;
       - `top_k` sets `retrieval.top_k`;
       - `budget` sets `enrich.max_context_tokens`;
       - `out` sets `output.dir`, resolved against the current directory;
       - `only` and `reingest` are copied.
2. **`src/hermes_report/questions.py`**, `__all__` = the names below.
   - `normalise(text: str) -> str`: lower-case, accents stripped (NFD minus
     `Mn` characters), and every whitespace run collapsed to one space and
     stripped. Collapsing whitespace is new against the playground, so that
     evidence phrases match across line breaks.
   - `QuestionsError(Exception)`, same shape as `ConfigError` (`path`,
     `message`, `key`), where `key` is like `"questions[2].keywords"`.
   - `Question` (frozen): `id: str`, `question: str`, `expected: str`,
     `keywords: tuple[str, ...] = ()`, `evidence: tuple[str, ...] = ()`,
     `documents: tuple[str, ...] = ()`, `refusal: bool = False`. Methods:
     - `matches(self, answer: str) -> bool | None`: `None` without keywords,
       else whether every normalised keyword is in the normalised answer;
     - `reachable(self, text: str) -> bool | None`: `None` without
       evidence, else whether every normalised phrase is in the normalised
       text;
     - `to_dict(self) -> dict[str, Any]`, with every field and tuples as
       lists.
   - `QuestionSet` (frozen): `path: Path`, `title: str | None`, `questions:
     tuple[Question, ...]`. It has a property `ids -> tuple[str, ...]` and
     a method `get(self, question_id: str) -> Question`, which raises
     `KeyError`.
   - `load_questions(path: Path, corpus_sources: Collection[str] | None =
     None) -> QuestionSet`, raising `QuestionsError`:
     - The file must exist and be valid JSON, as an object with keys
       `questions` (required, a non-empty list) and `title` (optional
       string). Any other key is an error.
     - Each question is an object with the keys of design §3.2 only.
       Required: `question` and `expected`, as non-empty strings.
     - `id`:
       - optional, defaulting to `q01`, `q02`... by 1-based position (zero
         padded to at least 2 digits);
       - must match `^[A-Za-z0-9_-]+$`, because it is used in URL anchors;
       - unique, and a duplicate is an error that names both positions.
     - `keywords`, `evidence` and `documents` are lists of non-empty
       strings.
     - `refusal` is a bool.
     - When `corpus_sources` is given, every entry of `documents` must be in
       it. The error lists the unknown ones.
3. **`src/hermes_report/corpus.py`**, `__all__` = the names below.
   - `CorpusError(Exception)` with a Spanish message.
   - `CorpusDocument` (frozen): `source: str` (path relative to the corpus
     folder, `/` separators), `path: Path` (absolute), `sha256: str` (hex
     digest of the bytes) and `chars: int` (length of the decoded text).
     Method `read_bytes(self) -> bytes`.
   - `Corpus` (frozen): `dir: Path`, `glob: str`, `documents:
     tuple[CorpusDocument, ...]`, sorted by `source`. Properties:
     - `sources -> tuple[str, ...]`;
     - `fingerprint -> str`: the sha256 hex digest of the lines
       `f"{source}:{sha256}\n"` in `source` order.
   - `load_corpus(dir: Path, glob: str = "**/*.md") -> Corpus`, raising
     `CorpusError` when:
     - `dir` is not a folder;
     - no regular file matches;
     - a file is not valid UTF-8, naming it.
4. `.api` files next to the new sources (`config.api`, `questions.api`,
   `corpus.api`), per `.claude/api-spec.md`.

- `src/hermes_report/corpus.py` — attempt 3: `resolve`/`is_dir`, `glob`/`is_file`, `relative_to` and read/decode wrapped with `_INPUT_ERRORS` (NUL byte, over-long name, permission, bad glob); a file name that is not valid UTF-8 is rejected.

**.api files written (pending relocation by `just relocate`):**
- none changed: no public signature or first docstring line changed (the `Overrides` summary line is the same), so `config.api`, `questions.api`, `corpus.api` stand.

**Design decisions:**
- Class fix, not instance fix: the same tuple at every call that touches the filesystem or a parser, with the specific errors (`TOMLDecodeError`, `JSONDecodeError`, `UnicodeDecodeError`, `RecursionError`) caught first for better messages.
- `Path("")` equals `Path(".")` in pathlib, so `Overrides(out=Path(""))` cannot be told from `--out .`; both are rejected, and the message asks for an explicit path. The CLI can pass an absolute path for the current folder.
- `Overrides.only` as a `str` raises `ConfigError` (not `TypeError`), key `only`, like any other bad override.
- Padding of other TOML values (e.g. `judge.model = " m "`) is not stripped; only the two environment variables, as asked.
- Earlier decisions (RunConfig.path out of equality, 0-based error keys, blank env vars as unset, etc.) are unchanged.

**Out of scope / pending:**
- Spec gap in `.api` (flagged earlier): order of `self.x` attributes inside a class block.
- Duplicate JSON object keys still resolve to the last one; symlinks under `**` are not specially handled; `MemoryError` on enormous files is not handled.

**Verification performed (build/lint only):**
- `uv run just check` → ruff check, ruff format --check, mypy strict pass; pytest 514 passed.
- Ad-hoc probe script (scratchpad, not a test) of NUL / surrogate paths, directory as file, bad globs, blank overrides: every hostile input gives the module error.
