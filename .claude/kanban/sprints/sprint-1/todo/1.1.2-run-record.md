## Tarea

Implement `src/hermes_report/record.py`, the schema of `run.json`. Every
report is rendered from this file. The design is
`.claude/architect/designs/report-generator/design.md` §6; this task fixes
the exact fields.

1. **Constants and errors**:
   - `SCHEMA_VERSION: Final = 1`;
   - `RecordError(Exception)`, with a Spanish message.
2. **`TypedDict`s** (all `total=True`). `X | None` means the key is always
   present, with `null` when absent. Lists stay lists: tuples become lists
   after a JSON round trip, so declare `list[...]`.
   - `VectorSummary`: `dimension: int`, `norm: float`, `head: list[float]`
     (the first 8 values, or fewer).
   - `PointRecord`: `id: str` (the Qdrant id as a string), `payload:
     dict[str, Any]`, `vector: VectorSummary | None`.
   - `DocumentRecord`: `source: str`, `sha256: str`, `chars: int`, `chunks:
     int`.
   - `CorpusRecord`: `dir: str`, `glob: str`, `fingerprint: str`,
     `documents: list[DocumentRecord]`.
   - `IngestDocumentRecord`: `source: str`, `chunks: int`, `seconds:
     float`, `cached: bool`.
   - `IngestRecord`: `seconds: float`, `chunker: dict[str, Any]`,
     `embedding: dict[str, Any]` (`provider`, `model`, `dimension`),
     `ingester_version: str`, `documents: list[IngestDocumentRecord]`.
   - `CollectionRecord`: `name: str`, `url: str`, `reloaded: bool`,
     `points: int`, `vector_size: int`, `distance: str`, `indexes:
     list[str]`.
   - `EnvironmentRecord`: `python: str`, `packages: dict[str, str]`,
     `ollama_host: str`, `qdrant_url: str`.
   - `RetrievedChunkRecord`: `chunk_id: str`, `text: str`, `score: float`,
     `vector_score: float | None`, `collection_name: str`, `metadata:
     dict[str, Any]` (the payload without its `"text"` key).
   - `SearchedQueryRecord`: `text: str`, `chain: list[str]`.
   - `RetrievalRecord`: `seconds: float`, `chunks:
     list[RetrievedChunkRecord]`, `queries: list[SearchedQueryRecord]`.
   - `ChunkRefRecord`: `chunk_id: str`, `collection_name: str`, `source:
     str | None`, `doc_id: str | None`, `chunk_index: int | None`, `score:
     float | None`, `origin: list[str]`.
   - `PieceRecord`: `text: str`, `transforms: list[str]`, `chunks:
     list[ChunkRefRecord]`.
   - `ContextRecord`: `pieces: list[PieceRecord]`, `enrichments:
     list[str]`, `dropped_chunk_ids: list[str]`, `query_id: str | None`.
   - `ChunkRangeRecord`: `collection_name: str`, `doc_id: str`, `first:
     int`, `last: int`.
   - `StoreReadRecord`: `ranges: list[ChunkRangeRecord]`, `returned:
     list[str]` (chunk ids), `seconds: float`.
   - `StepRecord`: `name: str`, `phase: str` (the `EnrichmentPhase`
     member name), `seconds: float`, `before: ContextRecord`, `after:
     ContextRecord`, `reads: list[StoreReadRecord]`.
   - `EnrichRecord`: `seconds: float`, `budget: dict[str, Any]`
     (`max_context_tokens`, `max_chunks`), `steps: list[StepRecord]`,
     `context: ContextRecord | None`.
   - `MessageRecord`: `role: str`, `content: str`.
   - `LLMCallRecord`: `messages: list[MessageRecord]`, `params: dict[str,
     Any]`, `reply: dict[str, Any] | None` (`text`, `model`,
     `prompt_tokens`, `completion_tokens`), `error: str | None`, `seconds:
     float`.
   - `GenerationRecord`: `seconds: float`, `llm_calls:
     list[LLMCallRecord]`, `result: dict[str, Any] | None` (the
     `GenerationResult`, see `generation_result_record`).
   - `RuleRecord`: `verdict: str`, `in_retrieval: bool | None`,
     `in_context: bool | None`, `in_cited: bool | None`, `answer_ok: bool |
     None`, `retrieved_rank: int | None`, `expected_docs_retrieved: bool |
     None`.
   - `JudgeRecord`: `verdict: str | None`, `reason: str | None`, `model:
     str`, `seconds: float`, `messages: list[MessageRecord]`, `raw: str |
     None`, `error: str | None`.
   - `QuestionRecord`: `spec: dict[str, Any]` (`Question.to_dict()`),
     `query_id: str`, `seconds: float`, `error: str | None`, `retrieval:
     RetrievalRecord | None`, `enrich: EnrichRecord | None`, `generation:
     GenerationRecord | None`, `rules: RuleRecord | None`, `judge:
     JudgeRecord | None`.
   - `RunRecord`: `schema: int`, `title: str`, `description: str`,
     `started_at: str` and `finished_at: str` (ISO 8601, local time with
     offset), `seconds: float`, `config: dict[str, Any]`
     (`RunConfig.to_dict()`), `environment: EnvironmentRecord`, `corpus:
     CorpusRecord`, `ingest: IngestRecord`, `collection: CollectionRecord`,
     `points: list[PointRecord]`, `questions: list[QuestionRecord]`.
3. **Converters**. They are pure functions, each returning a fresh record:
   - `vector_summary(vector: Sequence[float]) -> VectorSummary`, with the
     Euclidean norm;
   - `point_record(point_id: str | int, payload: Mapping[str, Any], vector:
     Sequence[float] | None) -> PointRecord`;
   - `retrieved_chunk_record(chunk: RetrievedChunk) ->
     RetrievedChunkRecord`;
   - `searched_query_record(query: SearchedQuery) -> SearchedQueryRecord`;
   - `context_record(context: EnrichedContext) -> ContextRecord`.
     `ChunkRefRecord.source` is `chunk.metadata.get("source")` when it is a
     `str`. `doc_id` and `chunk_index` come from `chunk.position`, or are
     `None` without it. `PieceRecord.text` is `piece.text`.
   - `chunk_range_record(chunk_range: ChunkRange) -> ChunkRangeRecord`
     (`hermes_enrich.store.ChunkRange`, imported from `hermes_enrich`);
   - `message_record(message: PromptMessage) -> MessageRecord`;
   - `generation_result_record(result: GenerationResult) -> dict[str,
     Any]`: `dataclasses.asdict(result)` with every tuple turned into a list
     (recursively), so it equals its JSON round trip.
   - `json_safe(value: Any) -> Any`: the recursive tuple-to-list helper,
     public because the pipeline reuses it.
4. **I/O**:
   - `write_record(record: RunRecord, path: Path) -> None` writes UTF-8 JSON
     with `ensure_ascii=False` and `indent=1`, creating the parent folder.
   - `read_record(path: Path) -> RunRecord` raises `RecordError` for a
     missing file, invalid JSON, a value that is not an object, or a
     `schema` that is missing or differs from `SCHEMA_VERSION`. Each message
     names the file. Beyond that it does no deep validation: it returns the
     loaded object `cast` to `RunRecord`.
5. `record.api` next to the source.

**Acceptance criteria**

  (`RetrievedChunk`, `SearchedQuery`, `EnrichedContext` with `ContextPiece`
  and `ContextChunk` carrying `ChunkPosition`, `ChunkRange`,

  - every converter, field by field;
  - that each converter's output equals its `json.loads(json.dumps(...))`;
  - the `write_record` / `read_record` round trip of a full `RunRecord`;
  - every `RecordError` case.
- `uv run just check` is green.

## Contexto

**Decisions taken** (by José, not reopened):
- The report is rendered only from `run.json`, never from live objects.
- Vectors are summarised, never stored whole.
- `TypedDict` rather than classes, so that reading needs no conversion code.

**Relevant files:**
- `.claude/architect/designs/report-generator/design.md` §6.
- The Hermes contract types, installed in `.venv`:
  - `hermes_core.retrieval` (`RetrievedChunk`, `SearchedQuery`);
  - `hermes_core.enrichment` (`EnrichedContext`, `ContextPiece`,
    `ContextChunk`, `ChunkPosition`);
  - `hermes_core.generation` (`GenerationResult`, `PromptMessage`,
    `Citation`, `SourcePiece`, `SourceChunk`);
  - `hermes_enrich` (`ChunkRange`).

**Constraints:**

  which it stores as plain dicts. Do not import `config` or `questions`.
- Use only the public API of the Hermes modules (`.claude/CLAUDE.project.md`).
