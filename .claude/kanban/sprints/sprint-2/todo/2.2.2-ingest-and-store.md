## Tarea

Implement the ingestion with its cache (`src/hermes_report/ingest.py`) and
the Qdrant collection (`src/hermes_report/store.py`). Design §5.1 and §5.2.

1. **`ingest.py`**
   - `IngestError(Exception)`, with a Spanish message that names the
     `source`.
   - `IngestedDocument` (frozen): `source: str`, `points:
     tuple[QdrantPoint, ...]`, `seconds: float`, `cached: bool`.
   - `Ingestion` (frozen): `documents: tuple[IngestedDocument, ...]`,
     `seconds: float`, `chunker: dict[str, Any]` (`name`,
     `max_chunk_size`, `hard_boundary_levels` as a list,
     `strip_frontmatter`), `embedding: dict[str, Any]` (`provider`,
     `model`, `dimension`; `dimension` is the length of the first vector,
     or `None` without points), `ingester_version: str`, `key: str`.
     Property `points -> tuple[QdrantPoint, ...]`, all of them in document
     order.
   - `ingest_corpus(corpus: Corpus, ingest: IngestConfig, embedding:
     EmbeddingConfig, embedder: Embedder, cache_dir: Path, force: bool =
     False, progress: Callable[[str], None] | None = None) -> Ingestion`:
     - Per document, it runs `MarkdownIngester(embedder,
       chunker=MarkdownStructuralChunker(hard_boundary_levels=list(...),
       max_chunk_size=..., strip_frontmatter=...)).ingest(MarkdownInput(content=doc.read_bytes()),
       doc.source)`.
     - `ingester_version` is
       `importlib.metadata.version("hermes-ingest-md")`.
     - The cache file is `cache_dir / f"{sha256(key_json)}.jsonl"`.
       `key_json` is `json.dumps({...}, sort_keys=True)` of: `source`,
       `sha256`, the chunker dict, the embedding `provider` and `model`,
       and `ingester_version`.
       - Each line is `{"id", "vector", "payload"}`.
       - A hit rebuilds the `QdrantPoint`s.
       - A miss, or `force`, ingests and then writes the file atomically
         (write a temp file in `cache_dir`, then `os.replace`), creating
         `cache_dir`.
       - A cache file that cannot be read or parsed counts as a miss.
     - `progress` gets one Spanish line per document (for example
       `"capitulo-01.md: 14 chunks (caché)"`).
     - `Ingestion.key` is the sha256 hex digest of `json.dumps({"corpus":
       corpus.fingerprint, "chunker": ..., "embedding": {"provider",
       "model"}, "ingester_version": ...}, sort_keys=True)`.
     - Two documents that produce the same point id (identical content
       under two paths) raise `IngestError` naming both sources.
     - Any exception of the ingester or the embedder becomes `IngestError`
       with the source and the original message. A `ProviderError` keeps
       its own message inside.
2. **`store.py`**
   - `PREFIX: Final = "hermes_report_"` and `StoreError(Exception)`.
   - `slug(text: str) -> str`: `normalise`, every run of characters that
     are not `[a-z0-9]` becomes `_`, stripped of `_`, at most 40
     characters. An empty result is `"run"`.
   - `collection_name(title: str, ingestion_key: str, explicit: str = "")
     -> str` returns `explicit` when set, else `f"{PREFIX}{slug(title)}_{ingestion_key[:8]}"`.
   - `make_client(url: str) -> QdrantClient`: `":memory:"` gives
     `QdrantClient(":memory:")`, anything else `QdrantClient(url=url,
     timeout=60)`.
   - `CollectionInfo` (frozen): `name`, `url`, `reloaded: bool`, `points:
     int`, `vector_size: int`, `distance: str`, `indexes: tuple[str, ...]`.
   - `ensure_collection(client: QdrantClient, name: str, points:
     Sequence[QdrantPoint], url: str, force: bool = False) ->
     CollectionInfo`:
     - A `name` without `PREFIX` raises `StoreError` before any call.
       Empty `points` raises `StoreError` ("el corpus no produjo ningún
       chunk").
     - Reuse when the collection exists, `not force`, its exact count
       equals `len(points)` and every point id is present (checked with
       `client.retrieve` in batches of 256, without payload or vectors).
     - Otherwise it deletes the collection if it exists, then creates it
       with `VectorParams(size=len(points[0].vector),
       distance=Distance.COSINE)`. It adds payload indexes `doc_id`
       (keyword) and `chunk_index` (integer), and upserts in batches of 256
       with `wait=True`.
     - `indexes` are the sorted payload-schema keys of the collection
       info, or `("chunk_index", "doc_id")` when the local mode reports
       none.
     - Any `qdrant_client` or connection exception becomes `StoreError`
       with the URL ("Qdrant no responde en <url> (...)").
   - `read_points(client: QdrantClient, name: str) -> list[PointRecord]`:
     - `client.scroll` over the whole collection, pages of 256, with
       payload and vectors;
     - converted with `record.point_record`;
     - sorted by `(payload source, payload chunk_index, id)`, treating a
       missing value as `""` / `-1`;
     - errors become `StoreError`.
     - A collection with a named-vector config is out of scope: `vector`
       is the single unnamed vector, or `None`.
3. `ingest.api` and `store.api` next to the sources.
