## Tarea

Implement `src/hermes_report/providers.py`, the embedders and LLM clients
of a run. Design: `.claude/architect/designs/report-generator/design.md`
§3.1 and §10.

1. `ProviderError(Exception)`, with a Spanish message.
2. `ollama_host() -> str`. It returns `$OLLAMA_HOST` stripped, or
   `http://localhost:11434` when that is unset or blank, and prepends
   `http://` when there is no `://`.
3. `OllamaEmbedder`, which satisfies `hermes_core.protocols.Embedder`
   structurally. `__init__(self, model: str, host: str | None = None,
   client: Any | None = None)`:
   - `client` is an `ollama.Client`, or any object with the same `embed`
     method; it is injected by tests. `None` builds `ollama.Client(host=host
     or ollama_host(), timeout=600)`.
   - Task prefixes, by model name without its `:tag`: for
     `nomic-embed-text`, queries get `"search_query: "` and documents
     `"search_document: "`. Other models get no prefix.
   - `get_query_embedding`, `get_text_embedding` and
     `get_text_embedding_batch` call `client.embed(model=..., input=[...])`
     in batches of 64 and read `response["embeddings"]` (also works as
     `response.embeddings`).
   - Any exception from the client becomes a `ProviderError` that names the
     model and the host. So does a wrong number of embeddings.
4. `HashEmbedder(dimension: int = 256)`, a deterministic offline embedder
   for tests and examples, with the same three methods.
   - Tokens are `re.findall(r"\w+", questions.normalise(text))`.
   - Each token adds `+1.0` or `-1.0` to index `int(h[:8], 16) % dimension`,
     where `h` is the sha256 hex digest of the token, and the sign comes
     from the parity of `int(h[8:10], 16)`.
   - The vector is L2-normalised.
   - A text without tokens, or one whose sum is all zeros, gives the unit
     vector `[1.0, 0.0, ...]`.
   - Queries and documents are embedded the same way.
   - `dimension < 1` raises `ValueError`.
5. `EchoLLM`, which satisfies `hermes_generator.LLMClient`, with `model =
   "echo"`. `complete(messages, params) -> LLMReply`:
   - It reads the `<source n="N" doc="...">` blocks of the last message.
     The tag format is in `hermes_generator/answer/prompt.py`; each block
     closes with that module's closing tag.
   - Without sources it replies `"INSUFFICIENT_CONTEXT"`
     (`hermes_generator.answer.codec.SENTINEL`).
   - Otherwise it replies with the first sentence of source 1, plus `"
     [1]"`. The sentence runs up to and including the first `.`, `!` or `?`,
     or is the first 200 characters, whitespace collapsed.
6. Judge clients, protocol `JudgeClient` with `model: str` and
   `complete_json(self, messages: Sequence[PromptMessage]) -> str` (the raw
   reply text):
   - `OllamaJudgeClient(model: str, host: str | None = None, client: Any |
     None = None)` calls `client.chat(model=model, messages=[{"role",
     "content"}...], format="json", options={"temperature": 0})` and returns
     the message content. Errors become `ProviderError`.
   - `EchoJudgeClient`, with `model = "echo"`, always returns
     `{"verdict": "partial", "reason": "juez simulado: no evalúa la
     respuesta"}` as JSON.
7. Factories:
   - `make_embedder(config: EmbeddingConfig) -> Embedder`;
   - `make_llm(config: GenerationConfig) -> LLMClient`. For `ollama` it
     builds `hermes_generator.answer.llm_ollama.OllamaChatClient(ollama.Client(host=ollama_host(),
     timeout=600), config.model)`; for `echo`, `EchoLLM()`.
   - `make_judge(config: JudgeConfig) -> JudgeClient`.
8. `check_ollama(models: Sequence[str], host: str | None = None, client:
   Any | None = None) -> None` calls `client.list()` once.
   - It raises `ProviderError` when Ollama does not answer ("Ollama no
     responde en <host> (...)").
   - It also raises when a model is not pulled ("el modelo 'x' no está
     descargado en <host>; ejecuta `ollama pull x`"). A name without a tag
     matches `name:latest`.
   - The model names come from `response["models"][i]["model"]`, or from
     the `model` / `name` attribute.
   - An empty `models` makes no call.
9. `providers.api` next to the source.

**Design decisions:**
- Boundary: every `Exception` raised by an injected or built client, or by reading its response, becomes `ProviderError` (chained with `from`). `KeyboardInterrupt` and other `BaseException` pass through. Argument validation happens before the `try`, so bad arguments raise `TypeError` / `ValueError` and never `ProviderError`.
- Responses are read with `_read`: `response[name]` first, then `response.name`, so dicts, pydantic responses and plain fakes all work. Malformed embeddings (not numbers, bool, NaN/inf, empty vector, different dimensions in one answer, wrong count) are `ProviderError`.
- `HashEmbedder` sign: even `int(h[8:10], 16)` gives `+1.0`, odd gives `-1.0` (the task text does not say which parity is which).
- `EchoLLM`: source blocks are matched with `<source n="N" doc="...">\n...\n</source>` (the closing tag constant of `prompt.py` is private, so the literal is used; the generator escapes any closing tag inside the text). Uses the block numbered 1, or the first block if none is numbered 1. The sentence ends at the first `.`, `!` or `?` with no 200-character cap in that case; without a terminator it is the first 200 characters. An empty source 1 gives just `[1]`. `params` must be a `GenerationParams` (TypeError otherwise); empty `messages` is a ValueError.
- Judge messages and `check_ollama` arguments are validated the same way (non-str sequences, blank names). `check_ollama` raises on the first missing model, in the order given. Model names reported by Ollama without a tag are also read as `:latest`. Entries with neither `model` nor `name` are ignored. Without an injected client it builds `ollama.Client(timeout=10)`; the embedders and judges use 600 s.
- `check_ollama` validates arguments before the empty-`models` shortcut, so a bad `host` raises even with no models.
- `make_*` raise `ValueError` for an unknown provider (config validation already prevents it) and `TypeError` for a wrong config type. `make_llm` uses `ollama_host()` as specified.
- Registry tags: `embedder[ollama|hash]`, `llm_client[echo]`, `judge_client` (+ `[ollama]`, `[echo]`).
