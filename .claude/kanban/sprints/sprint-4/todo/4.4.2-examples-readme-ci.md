## Tarea

Ship two ready examples, the README, and a CI that can read the private
dependencies.

1. **`examples/demo/`**, committed:
   - `corpus/`: 4 to 6 short invented Markdown documents with H1/H2
     headings, in two sub-folders. Their facts are invented so that no model
     knows them. Reuse the playground scenario corpus (Nébula Logística,
     Faro, Brújula) from
     `/home/jose/CT/Hermes/Hermes-Generator/hermes-generator/playground/scenarios.py`
     (branch `dev`).
   - `preguntas.json`: 6 to 8 questions, with `keywords`, `evidence` and
     `documents`. Include:
     - one answered from one chunk;
     - one that needs neighbouring chunks;
     - one across two documents;
     - one refusal;
     - one without keywords (judge only).
   - `run.toml`: Ollama defaults (`nomic-embed-text`, `qwen3:4b`) and a
     clear title.
   - `run-offline.toml`: the same corpus with `embedding.provider = "hash"`,
     `generation.provider = "echo"`, `judge.provider = "echo"` and
     `qdrant.url = ":memory:"`.
   - `tests/test_examples.py` runs `run-offline.toml` end to end into
     `tmp_path` and checks that the folder holds `run.toml`, `run.json` and
     `report.html`.
2. **`examples/quijote/`**:
   - `prepare.py`, run as `uv run python examples/quijote/prepare.py`,
     standard library only:
     - It downloads Project Gutenberg ebook 2000 once into
       `examples/quijote/data/` (git-ignored).
     - It ports `to_markdown` from the playground's `quijote/corpus.py`.
     - It writes one Markdown file per chapter, from
       `examples/quijote/corpus/parte-1/capitulo-01.md` to
       `parte-2/capitulo-74.md` (git-ignored). Each file starts with `#
       <book>` and `## <chapter heading>`, so that `heading_path` stays
       `[book, chapter]`.
     - It prints the counts and checks that there are 52 + 74 chapters,
       exiting 1 otherwise.
   - `preguntas.json`: the 11 battery questions of
     `playground/quijote/questions.py`, with the same text, expected answer,
     keywords and evidence. `documents` are the chapter files, so
     `(BOOK_I, "VIII")` becomes `parte-1/capitulo-08.md`. q11 is a refusal.
   - `run.toml`: Ollama defaults, `top_k = 10` and a budget of 3000.
   - A test checks that `preguntas.json` matches the playground battery
     field by field. The expected data is hard-coded in the test, so it
     needs no playground import.
3. **`.gitignore`**: add `examples/*/data/`, `examples/quijote/corpus/`,
   `out/` and `.hermes-report-cache/`.
4. **`README.md`**, in Spanish, covering:
   - what the tool does, with its phases;
   - requirements: Ollama with the models, and Qdrant;
   - install: `uv sync`, plus ssh access to the private repositories;
   - quick start with the demo, both offline and with Ollama;
   - the Quijote example;
   - the run file and questions formats: list the main keys and point to
     the design for every key;
   - the outputs, and how to read the report tabs;
   - `render` and `compare`;
   - how to bump the pinned modules.
5. **CI** (`.github/workflows/ci.yml`):
   - Before `uv sync`, add `git config --global` rewrites that send both
     `ssh://git@github.com/` and `https://github.com/` to
     `https://x-access-token:${{ secrets.HERMES_DEPS_TOKEN }}@github.com/`.
   - Set `persist-credentials: false` on checkout, as hermes-generator does.
   - Add a comment that José must create the secret (FU-1).
