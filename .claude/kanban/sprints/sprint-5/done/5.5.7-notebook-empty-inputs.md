## Tarea

Make `notebooks/rag_evaluation.ipynb` handle empty inputs. Today, with an
empty dataset (`[]` or `{"questions": []}`) or an empty `collections`
list, the cell `s5-example` does `items[collection][0]` and raises
`IndexError`, so no history row is written (Carlos, 5.5.6 review; pinned by
a strict xfail in `tests/test_notebook.py`).

1. Guard the example cell: when there is nothing to show, print a clear
   Spanish message instead of failing.
2. Decide the end-to-end behaviour and make every later cell consistent:
   - empty dataset: each collection still gets one history row with
     `n_questions = 0`, empty means and 0 errors, so the run is visible in
     the history;
   - empty `collections`: no row is written and the notebook says so in
     Spanish; it does not fail.
3. Store the notebook without outputs (`just notebook-clean`).

**Acceptance criteria**
- The strict xfail for the empty dataset becomes a normal passing test,
  and Carlos adds one for an empty `collections` list.
- The other `tests/test_notebook.py` tests still pass unchanged.
- `uv run just check` is green.
