## Tarea

Create `notebooks/rag_evaluation.ipynb`, its dependency group, its test
and the README sections. Design §4 ("Notebook") and ADR 0003.

1. **Dependencies**: `uv add --group notebook pandas jupyterlab ipykernel
   nbclient` (approved by José, 2026-10-22). Nothing else.
2. **Notebook**, with the eight sections of the design, each code cell
   commented (what and why) and showing its intermediate result:
   setup; one `CONFIG` dict (collections, embedding, generation, judge,
   `top_k`, `score_threshold`, payload filters, metrics selection,
   dataset path, insufficient message, note); the offline collection;
   dataset loading (JSON array or `{"title", "questions"}`,
   `ground_truth` alias of `expected`); retrieval and generation with
   `qdrant_client` and `hermes_report.providers`; metrics with
   `hermes_report.metrics`; one experiment row per collection; history in
   `history.csv` + `history.jsonl` + `<run_id>-detail.csv`, then reload
   and sort.
3. **Offline mode** with `HERMES_NOTEBOOK_OFFLINE=1`: `HashEmbedder`,
   `EchoLLM`, `EchoJudgeClient`, Qdrant `":memory:"` and the collection
   `hermes_report_notebook_demo` built from `examples/demo/corpus`.
   `HERMES_NOTEBOOK_OUT` sets the output folder (default `notebooks/out/`,
   git-ignored).
4. **README** (Spanish): a "Métricas" section (families, defaults,
   `[metrics]`, `--metric`, `--no-metrics`) and a "Notebook de
   experimentos" section (`uv sync --group notebook`, `uv run jupyter lab`,
   how to change `CONFIG`, where the history goes).
5. A `just` recipe or test that checks the notebook has no stored outputs.

**Acceptance criteria**
- A test (not `integration`) runs the whole notebook with `nbclient` in
  offline mode into `tmp_path`, twice with different `top_k`, and checks
  that `history.csv` has two comparable rows with the required columns.
- An `integration` test runs it against real Ollama and Qdrant over a
  collection of `examples/quijote` and skips when they are unreachable.
- The notebook never creates, deletes or writes a collection that does not
  start with `hermes_report_`.
- The notebook is stored without outputs.
- `uv run just check` is green.

## Contexto

**Decisions taken:**
- The notebook does its own retrieval and generation (José; ADR 0003). The
  exception is confined to `notebooks/`: the package gains no retrieval
  or generation.
- It imports the metrics from `hermes_report.metrics`; it does not
  duplicate them.

**Relevant files:**
- `src/hermes_report/providers.py`, `ingest.py`, `store.py`, `metrics/`.
- `examples/demo/`, `README.md`, `.gitignore`, `pyproject.toml`, `justfile`.

**Constraints (epic 5, all tasks):**
- Design: `.claude/architect/designs/rag-metrics/design.md` (approved); ADRs 0002 and 0003. Follow its names, signatures and formulas.
- No new dependency in the package. The only approved ones are pandas, jupyterlab, ipykernel and nbclient, in the `notebook` dependency group (task 5.5.6 only). No ragas, deepeval, langchain, sacrebleu or rouge-score.
- Metrics are separate signals: they never change the rule verdict, the judge verdict or the exit code of a run.
- Tests never touch José's resources: Qdrant `":memory:"`, `HashEmbedder`, `EchoLLM`, `EchoJudgeClient` or scripted fake judge clients.
- Judge prompts and any text shown to people in Spanish; identifiers, comments and docstrings in English.
- Use only the public API of the Hermes modules (see `.claude/CLAUDE.project.md`).
