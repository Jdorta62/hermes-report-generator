# `.api` format — specification v2

Normative contract for `llm-apigen`. Manuel implements against it, Carlos writes
golden files from it (never from the implementation), Diego cites it.
Any behavior not described here is a spec gap: report it in the handoff under
"Out of scope / pending" instead of improvising.

## 1. Principles

1. Describe the **interface and contract**, never the implementation.
2. Python-like syntax: the reader is an LLM trained on Python.
3. ASCII only in generated syntax (non-ASCII symbols cost extra tokens).
4. **No inference.** Everything comes from the AST or from docstring tags.
   Missing information is omitted or marked `?`, never guessed.
5. Deterministic: same input + same config → byte-identical output.

## 2. Paths and files

- **Project root**: nearest ancestor of the working directory (or `--root`)
  containing `pyproject.toml`; else `.git/`; else the working directory.
- **Output directory**: `<root>/.claude/api/`. Created if missing
  (including `.claude/`).
- **Mirror rule**: source path relative to root, leading `src/` stripped,
  `.py` → `.api`.
  `src/llm_apigen/render.py` → `.claude/api/llm_apigen/render.api`
  `tools/foo.py` → `.claude/api/tools/foo.api`
  `pkg/__init__.py` → `.claude/api/pkg/__init__.api`
- **Dotted name**: same relative path, `/` → `.`, `.py` and `.__init__` removed.
- A module with no public members after filtering produces **no file** and
  no INDEX line.
- Encoding UTF-8, LF line endings, exactly one trailing newline, no trailing
  spaces.
- **Header marker** — first line of every generated file (INDEX included):
  `# apigen-format: 2 | generated by apigen, do not edit`
  Only files carrying this marker (any format number) may ever be overwritten
  or deleted.

### 2.1 Changes from v1

- `@deps` and `@ext` module lines (§4.7).
- `Registry:` docstring tag rendered as `reg:` (§6).
- Marker and legend updated. A v1 file is still a valid v2 file that declares
  no dependencies and no registries: readers must treat its missing `@deps`
  as *unknown*, not as *none*.

## 3. INDEX.api

`<root>/.claude/api/INDEX.api`:

```
# apigen-format: 2 | generated by apigen, do not edit
# LEGEND
# kinds: C=class A=abstract D=dataclass I=protocol E=enum
# members: a=attr p=property m=method cm=classmethod sm=staticmethod am=abstractmethod f=function k=constant
# flags: ^=override [ro]=read-only [frozen]=frozen dataclass ?=unknown/unresolved
# contract: !=raises ~=effects(io|net|mut|gpu|proc) ::=summary req:=precondition ex:=usage reg:=registry[key] main:=CLI entry
# @reexport=public name imported from another module
# @deps=project modules imported @ext=third-party packages imported

@mod llm_apigen.ir :: Language-neutral intermediate representation -> llm_apigen/ir.api
@mod llm_apigen.render :: IR to .api text -> llm_apigen/render.api
```

- Legend lines are fixed text, byte-exact as above.
- One blank line after the legend, then one `@mod` line per generated module,
  sorted by dotted name. Summary omitted (with its `::`) if the module has none.
- The legend appears **only** in INDEX, never in module files.

## 4. Module file grammar

```
<header marker>
@mod <dotted.name>[ :: <summary>]
[@reexport <name> -> <origin.dotted>]...
[@deps <mod1>, <mod2>, ...]
[@ext <pkg1>, <pkg2>, ...]
<blank line>
<top-level items in source order>
```

Blank lines: exactly one blank line between two consecutive top-level items
when at least one of them is a class block. Consecutive `k` / `f` lines are
not separated. No blank lines inside a class block.

### 4.1 Indentation

Top-level items at column 0. Members at +2. Nested classes at +2, their
members at +4. Continuation lines (`req:`, `ex:`) at the owner's indent +2;
a class's own `reg:` and `ex:` go at member indent, in that order, before the
first member.

### 4.2 Class line

```
<K> <Name>[<type-params>][(<bases>)][ [frozen]][ :: <summary>]
```

Kind `K`, first match wins:

| K | Condition |
|---|---|
| `E` | inherits from `Enum` or a subclass (`IntEnum`, `StrEnum`, `Flag`...) |
| `I` | has `Protocol` / `Protocol[...]` among its bases |
| `D` | decorated with `@dataclass` / `@dataclasses.dataclass` (with or without args) |
| `A` | has `ABC` base, `metaclass=ABCMeta`, or defines at least one abstract method in its own body |
| `C` | anything else |

Bases rendered as written in source, in order, with these **omitted**:
`object`, bare `ABC`, bare `Protocol`, bare `Enum`, `metaclass=...`.
Parentheses are dropped if nothing remains. Other keyword arguments are dropped.
An unresolved base (see §8) gets a `?` suffix: `C Foo(ext.Base?)`.
PEP 695 type parameters are rendered as written: `C Repo[T: Model]`.
`[frozen]` only for `D` with `frozen=True`.

### 4.3 Enums

```
E <Name>[(<non-omitted bases>)] = <M1> | <M2> | ...[ :: <summary>]
```

Member names only, values omitted, source order. If the enum defines public
methods or properties, they follow as members.

### 4.4 Members

```
<kind>[^] [async ]<name>[<signature>][ -> <return>][ [ro]][ ! <E1>, <E2>][ ~<e1>,<e2>][ :: <summary>]
```

Suffix order is fixed exactly as shown.

- `a` attribute: `a <name>[: <type>][ = <default>][ [ro]][ :: <summary>]`
  - Class-body annotated/assigned names and instance attributes assigned in
    `__init__` (`self.x`). `[ro]` when annotated `Final`.
  - **Grouping**: consecutive `a` lines with type, without default, flags or
    summary are merged with `; `, max 4 per line:
    `a x: float; y: float; z: float`
- `p` property: `p <name> -> <type>[ [ro]]`. `[ro]` when there is no setter.
  `functools.cached_property` → `p` with `[ro]`.
- `m` / `cm` / `sm` / `am`: method, classmethod, staticmethod, abstractmethod
  (`am` wins over `m`; abstract classmethod renders `cm`).
- `f` module-level function. `k` module-level constant: UPPER_CASE name.
  Other module-level variables are omitted.
- `^` appended to the kind when a member with the same name exists in any
  **resolved** base (full MRO). Never on `__init__`.
- `async` prefix for `async def`.

### 4.5 Signatures

- Parameters as in Python source; first `self` / `cls` removed for methods.
- `/`, `*`, `*args: T`, `**kwargs: T` preserved.
- Missing annotation → name only (`timeout=5.0`).
- Defaults: source text, whitespace collapsed; longer than `max_default_len`
  (30) → `...`.
- Return: `-> None` is **omitted**; a missing return annotation renders
  `-> ?`; `__init__` never shows a return.
- String (forward-ref) annotations rendered without quotes: `"Aircraft"` → `Aircraft`.
- `@overload`: each overload is its own member line; the implementation is omitted.

### 4.6 Summary

First line of the docstring's first paragraph, trailing `.` removed, truncated
to `max_desc_len` (80) chars with `...` (total length ≤ 80). Absent → no `::`.

### 4.7 Dependencies (`@deps`, `@ext`)

Built from every static `import` / `from ... import` statement in the module,
at any nesting level (function bodies and `if TYPE_CHECKING:` included).
Dynamic imports (`importlib`, `__import__`) are ignored.

- Relative imports are resolved against the module's own package.
- **Project module**: a dotted name whose source file exists under the
  project root (§2 mirror rule, `src/` or not). For `from a.b import c`,
  the dependency is `a.b.c` if that is a project module, else `a.b`.
  For `import a.b`, the longest dotted prefix that is a project module.
- `@deps`: project modules, the module itself excluded. Members are never
  listed, only modules.
- `@ext`: top-level package name of every other import, excluding the
  standard library (`sys.stdlib_module_names` of the running interpreter)
  and `__future__`.
- Each line deduplicated, sorted, separated by `, `; omitted when empty.
  No wrapping, whatever the length.

## 5. Inclusion rules

- Private names (`_x`) omitted, at any level, unless `include_private = true`.
- Dunders omitted except `include_dunder` (default: `__init__`, `__call__`,
  `__enter__`, `__exit__`, `__aenter__`, `__aexit__`, `__iter__`, `__len__`,
  `__getitem__`).
- If a module defines `__all__` as a static list/tuple of strings, only those
  top-level names are public. Dynamic `__all__` → ignored + warning.
- Only members defined in the class body are listed; inherited, non-overridden
  members are never repeated.
- Dataclass-generated `__init__` is never rendered; an explicit `__init__` is.
- Imported names are not part of the module unless listed in `__all__`
  (then rendered as `@reexport <name> -> <origin.dotted>` after `@mod`).

## 6. Docstring contract tags

Google-style, parsed from the docstring of the class, method or function:

```python
"""Advance one tick.

Raises:
  FdmError: if the FDM diverges.
Effects: mut, io
Requires: init_conditions()
Example: ac.step(0.01)
"""
```

| Tag | Renders | Notes |
|---|---|---|
| `Raises:` section | `! E1, E2` | exception names only, source order, deduplicated |
| `Effects:` | `~e1,e2` | allowed: `io net mut gpu proc`; unknown values kept + warning |
| `Requires:` | continuation `req: <text>` | single line |
| `Example:` | continuation `ex: <text>` | inline form, or first non-empty line of block form |
| `Registry:` | continuation `reg: <entries>` | classes only; see below |

`Registry:` links an interface and its implementations without inferring it
from decorators or registration calls:

- `Registry: <name>` on the Protocol/ABC that **defines** registry `<name>`.
- `Registry: <name>[<key>]` on a class **registered** under `<key>`.
- Several entries comma-separated, rendered in source order with `, `:
  `reg: rerank[cross_encoder], scorer[ce]`.
- `<name>` matches `[a-z_][a-z0-9_]*`, `<key>` matches `[A-Za-z0-9_.-]+`.
  A malformed entry is dropped + warning; on a function or method the tag is
  ignored + warning.

Tags never leak into the summary. No tag is ever inferred from code
(e.g. a `raise` statement does not produce `!`).

## 7. CLI entry points (`main:`)

If a module contains `if __name__ == "__main__":`, append at the end:
`main: python -m <dotted>` (inside a package) or `main: python <relpath>`.
If `argparse` `add_argument` calls with literal arguments are statically found
in the module, append them: positional → `<name>`, optional → `[--flag]`,
optional with `type=` → `[--flag <type>]`. Anything non-literal → skipped.

## 8. Warnings

Written to stderr as `apigen: warning: <relpath>:<line>: <message>`.
Warnings never change the exit code. Required warnings:
unresolved base class, unknown effect value, dynamic `__all__`,
unknown config key, no virtualenv found (once per run), malformed or
misplaced `Registry:` entry.

Virtualenv resolution order (site-packages added to the search paths, no import
executed): `--venv` → `VIRTUAL_ENV` → `<root>/.venv` → none (+ warning).

## 9. CLI

```
apigen build [PATH ...] [--root DIR] [--venv DIR] [--stdout]
apigen check [PATH ...] [--root DIR] [--venv DIR]
apigen init  [--root DIR]
apigen --version
```

- `build` without PATH: configured `packages`, else auto-detect packages under
  `src/`, else top-level directories with `__init__.py`; `exclude` applied.
- `--stdout`: print instead of writing (single PATH only).
- A full `build` removes stale marker-carrying files under `.claude/api/`
  and empty directories left behind. A PATH-scoped build never deletes.
- `check`: generate in memory and compare with disk, INDEX and stale files
  included. Reports each differing file. If INDEX has a different format
  version: `generated with format N, tool uses format M; run 'apigen build'`.

| Exit | Meaning |
|---|---|
| 0 | success / up to date |
| 1 | `check` found differences |
| 2 | usage or configuration error |
| 3 | a target file could not be parsed |

## 10. Configuration

Optional `[tool.apigen]` in `<root>/pyproject.toml`. Precedence: CLI > file > defaults.

```toml
[tool.apigen]
packages = []                 # empty = auto-detect
exclude = ["tests", "docs"]
include_private = false
include_dunder = ["__init__", "__call__", "__enter__", "__exit__", "__aenter__", "__aexit__", "__iter__", "__len__", "__getitem__"]
max_desc_len = 80
max_default_len = 30
venv = ""                     # empty = resolution order of §8
```

## 11. Reference example

Input `src/sim/flight.py`:

```python
"""Flight dynamics over JSBSim."""
from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum
from pathlib import Path
from typing import Final

import jsbsim

from .errors import FdmError

DEFAULT_DT: Final = 0.01

class FlightMode(Enum):
  MANUAL = 1
  AUTO = 2
  HOLD = 3

@dataclass(frozen=True)
class State:
  """Kinematic state snapshot."""
  x: float
  y: float
  z: float
  t: float = 0.0

class Vehicle(ABC):
  """Anything the simulator can step.

  Registry: vehicle
  """

  @abstractmethod
  def step(self, dt: float) -> State:
    """Advance one tick."""

  def reset(self) -> None: ...

class Aircraft(Vehicle):
  """Fixed-wing aircraft; one instance per FDM.

  Registry: vehicle[fixed_wing]
  Example: ac = Aircraft.from_file(p); ac.step(0.01)
  """
  mass_kg: float = 0.0

  def __init__(self, cfg_path: Path, *, dt: float = DEFAULT_DT) -> None:
    """Load the aircraft model.

    Effects: io
    """
    self._fdm = None

  @property
  def altitude_m(self) -> float:
    return 0.0

  def step(self, dt: float) -> State:
    """Advance one tick.

    Raises:
      FdmError: if the FDM diverges.
    Effects: mut
    Requires: init_conditions()
    """

  @classmethod
  def from_file(cls, path: Path) -> "Aircraft":
    """Build from an XML file.

    Raises:
      FileNotFoundError: missing file.
    Effects: io
    """

  def _internal(self): ...

async def fetch_metar(icao: str, timeout=5.0):
  """Download a METAR report."""
```

Expected `.claude/api/sim/flight.api`:

```
# apigen-format: 2 | generated by apigen, do not edit
@mod sim.flight :: Flight dynamics over JSBSim
@deps sim.errors
@ext jsbsim

k DEFAULT_DT: Final = 0.01

E FlightMode = MANUAL | AUTO | HOLD

D State [frozen] :: Kinematic state snapshot
  a x: float; y: float; z: float
  a t: float = 0.0

A Vehicle :: Anything the simulator can step
  reg: vehicle
  am step(dt: float) -> State :: Advance one tick
  m reset()

C Aircraft(Vehicle) :: Fixed-wing aircraft; one instance per FDM
  reg: vehicle[fixed_wing]
  ex: ac = Aircraft.from_file(p); ac.step(0.01)
  a mass_kg: float = 0.0
  m __init__(cfg_path: Path, *, dt: float = DEFAULT_DT) ~io :: Load the aircraft model
  p altitude_m -> float [ro]
  m^ step(dt: float) -> State ! FdmError ~mut :: Advance one tick
    req: init_conditions()
  cm from_file(path: Path) -> Aircraft ! FileNotFoundError ~io :: Build from an XML file

f async fetch_metar(icao: str, timeout=5.0) -> ? :: Download a METAR report
```
